# Supplier Cost List Manager Tool
 
A web application for managing supplier price lists with AI-powered insights.

- Overview:

This tool allows businesses to manage and review supplier price lists efficiently. Users can view suppliers, compare price list versions, approve or reject incoming price lists, and ask AI-powered questions about pricing data.
Features

View and manage suppliers
Review new and historical price lists
Approve, reject, or partially deny price list items
AI assistant (Gemini) for natural language price queries
Download original supplier Excel files
